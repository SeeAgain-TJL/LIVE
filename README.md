# UNIVERSE OF ME · 我的人生宇宙

> 人生不是一条直线，而是一个不断扩张的宇宙。

一个以真实可交互 3D 星球承载人生阶段、以安静的结构化档案保存记忆的个人网站。项目当前为 **可构建和运行的本地开发原型**，已通过基础浏览器流程验证，尚未接入正式账号与云存储。

## 当前运行时：V4.1-R1

星球默认入口已改为全屏可探索的三维湖岸世界，不再先打开文章列表。点击星球飞近到达后直接进入，不附加固定停留。世界中的记忆对象对应已保存的 Memory ID；搜索、年份、列表、资料与旧记忆球展示可从「记忆管理」打开。地形、树林、水体与手动昼夜预设在没有记忆时也存在。宇宙导航/设置默认收起，电影模式和人物均有恢复入口。

这是风格化环境原型，尚未达到概念图的写实景观与文明细节，视觉验收仍由用户判断。实际录屏、截图、测试范围和限制见 [R1 审阅记录](docs/V4-R1-REVIEW.md)。以下 A3、角色和实验章节保留为历史背景，以本节和最新 PROGRESS 为准。

`/guide-lab` 用 `@pixiv/three-vrm 3.5.5` 加载带骨骼的官方授权 VRM 1.0 技术样本，验证转身、视线、指引后真实相机移动、欢迎，以及真实记忆球飞到手骨掌心锚点。**棕发样本不是最终银蓝原创角色，尚未通过最终角色美术验收，也没有替换正式 SVG 引导者。**

## 当前实现

- 四层入口：`/` 宇宙星系 → `/galaxy/[id]` 星球场景 → `/planet/[id]` 生命世界及真实记忆对象；可逐级返回。
- 全局唯一记忆引导者：默认人物独立、二维拖动/左右停靠、可展开对话与独立查找；位置、显示及自动台词偏好刷新保留。支持真实目的地导航和跨星球记忆查找，没有 AI。当前全身 SVG 明示为开发预览，最终高质量原创立绘仍待制作，已建立六状态可替换资产结构。
- React Three Fiber / Three.js 实时宇宙，五种程序化材质、行星自转、大气与星环。
- 拖动旋转、滚轮/双指缩放；单击/轻触 3D 星球平滑飞近并自动进入，Escape 取消飞行或渐变，返回原星系与进入前视角。悬停摘要和左侧列表独立查看资料。
- 独立星球记忆路由 `/planet/[id]`；镜头到达后直接进入三维世界，按需打开记忆档案。
- 创建/编辑星球：可留空名称、日期范围、持续阶段、介绍、星系、类型、配色、纹理与星环。
- 文字记忆新增、编辑、确认删除、日期排序；星球搜索、跨年份阶段筛选。
- 星穹记忆殿堂：真实 3D 记忆球、搜索/年份/类型定位、可收起引导者、独立阅读抽屉与键盘列表；支持文字、照片和视频。
- 本地版本化数据、基础校验、冲突检查、上一版快照、JSON 导出。
- 响应式页面、自动/高质量/简化模式、减少动态效果、WebGL 失败提示和档案直达链接。

**五颗初始星球都是外观示例，名称与人生日期均为空，没有自动生成用户经历。**

## 环境与启动

要求 Node.js 22.13+（本轮环境 Node 24.18.0）、npm 10+、支持 WebGL 的现代浏览器。

```powershell
# Windows 若 npm.ps1 受执行策略限制，使用 npm.cmd；不必修改系统执行策略。
npm.cmd ci
npm.cmd run dev
```

打开 http://127.0.0.1:3000 。macOS / Linux 使用 `npm` 替代 `npm.cmd`。

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd start
```

浏览器测试使用 Playwright 和 Chrome，在独立浏览器配置中创建测试资料，不修改日常浏览器数据：

```powershell
# 已安装 Chrome 时可跳过下一行；CI 会自动安装。
npx.cmd playwright install chrome
npm.cmd run test:e2e
```

`test:e2e` 使用已构建的应用并在独立的 **3100** 端口自动启动生产服务，不复用日常开发服务。可通过 `PLAYWRIGHT_PORT` 改端口；运行前先 `npm.cmd run build`。覆盖详情关闭/重开/切换、文字与媒体 CRUD/刷新、视频播放、引导查找，以及桌面/手机创建流程。

`node scripts/verify-config.mjs` 可在未安装依赖时检查项目配置、文档、UTF-8 文件和本地导入路径；它不能替代 `tsc` 或 Next.js 构建。

当前不需要 `.env`、数据库或存储密钥。`.env.example` 中未来配置均为注释，**当前不会读取它们，也没有云存储实现**。

## 本地数据与备份

- 当前使用 **浏览器 localStorage 元数据 + IndexedDB 媒体 Blob**，并非服务端磁盘、PostgreSQL 或云对象存储。
- 数据绑定浏览器、浏览器用户配置与站点 origin。`localhost`、`127.0.0.1` 和不同端口拥有不同数据，日常请固定访问地址。
- 数据未加密，没有账号和服务端访问控制，不应部署为正式私人记忆服务。请勿把本地版本作为重要资料的唯一副本。
- 清理站点数据、隐私模式结束、浏览器配额问题都可能导致本地记录不可用。
- 宇宙右上角「导出档案」或星系内「渲染与数据设置」可下载 JSON v2，含星球、星系、文字及媒体元数据，**不包含照片/视频 Blob**；请单独保留原始媒体。当前尚无完整媒体导出/恢复。
- 主数据键 `universe-of-me:data:v1`，上一版快照键 `universe-of-me:recovery:v1`，可选镜头键 `universe-of-me:camera:v1`。
- 键名与 schema v2 保持兼容。B1 首次读取旧档案时先把原文保存在 `universe-of-me:before-galaxies:v1`，再补充「未分类星系」和缺失的星球归属；已有星系、坐标、正文、媒体引用与 revision 保持不变，IndexedDB 不参与迁移。不覆盖已存在的迁移备份；写入失败会阻止载入而不会声称成功。旧 v1 同时补齐 v2 媒体字段。
- 星系镜头独立保存在 `universe-of-me:camera:v1:galaxy:<id>`，旧镜头键保留。C 起引导者偏好独立保存在 `universe-of-me:guide:v1`，包含左右边缘、归一化高度、显示、对话与自动提示开关；刷新保留，不改变档案 schema。未知/损坏偏好不被覆盖。
- 损坏/未知版本数据会阻止写入并提供原始导出入口，不会静默重置。上一版快照目前仅为手动救援准备，尚无恢复/导入界面。
- 若需手动救援，请先分别备份主键和快照原文，再依据 schema 校验；不要直接清空存储。自动导入、迁移与恢复演练是后续任务。

## B2 进出与返回验证

进入星系 → 调整视角 → 单击 3D 星球 → 自动飞近并进入记忆殿堂 → 新增/编辑记忆并保存 → 刷新重新查看 →「返回所属星系」→ 恢复出发视角 → 再点另一星球。飞行及渐变中按 Escape 可取消；拖动与双指不进入。资料管理仍从左侧列表访问。

引导者展开面板可关闭「飞行与抵达时显示简短提示」，C 起此偏好在客户端跨页及刷新后保留。可选 sessionStorage 键 `universe-of-me:visit:v1:<encoded planetId>` 保存本标签页的出发/抵达镜头，不属于记忆档案；失效时回到正确星系的书签/全景，不影响数据。B2 没有改变 schema v2、原有迁移或 IndexedDB。完整验收和限制见 `docs/PROGRESS.md`。

## C 引导者验证

点击人物 → 展开对话 →「带我去看看」选择真实星系/星球 → 飞行/抵达台词 →「帮我寻找」按关键词、年份和类型查找真实记忆 → 点击结果打开。人物可上下拖动并吸附左右边缘，松开不误开对话；隐藏后通过小入口恢复，位置与偏好刷新保留，阅读时自动紧凑。按方向键也可移动，Escape 关闭面板。

角色组件与素材分离，当前人物明确标为开发立绘预览；最终原创透明立绘和状态图的接入要求见 [资产契约](public/characters/memory-guide/README.md)。本轮没有生成最终高质量人物资产、接入 AI 或改变记忆存储。

## 项目结构

```text
src/
  app/                       # App Router、全局样式、错误与空页面
    galaxy/[id]/             # 所属星球的原有 3D 探索场景
    planet/[id]/             # 独立星球档案
  components/
    three/                   # 材质、星空、镜头与 Canvas（不直接访问业务数据）
    universe/                # 探索界面与交互协调
    galaxies/                # 宇宙星系入口
    guide/                   # 根布局唯一引导者、原创角色与记忆动作桥接
    planets/                 # 星球创建与编辑表单
    memories/                # 结构化文字档案、记忆编辑器
    providers/               # 应用状态、持久化提交
    ui/                      # 对话框、按钮、存储状态
  domain/                    # 类型、日期与阶段规则
  data/                      # 本地仓库、校验与明确标记的示例
tests/                       # 日期、存储与保护措施的真实行为测试
docs/                        # 产品、架构、进度与技术决策
```

继续开发前请依次阅读 [AGENTS.md](AGENTS.md)、[产品规范](docs/PRODUCT.md)、[架构](docs/ARCHITECTURE.md)、[进度](docs/PROGRESS.md)、[技术决策](docs/DECISIONS.md)。
