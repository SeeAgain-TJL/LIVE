# 记忆引导者资产契约

当前状态：**开发立绘预览，不是最终高质量角色交付**。当前环境未提供图像生成工具；未下载未授权角色，也未使用 API 密钥发送私人内容。

`src/components/guide/character-assets.ts` 是唯一资产清单。`source: null` 时使用项目原创 SVG 开发预览，并在 UI 标出「立绘开发预览」。最终素材应为原创/获得明确许可的成年银蓝长发女性角色、深蓝星空幻想服装，完整立姿、透明背景，无文字、水印或幼态特征。推荐 1024×2048 PNG/WebP；所有姿态保持相同画布、人物比例、脚底与眼睛基线，避免状态切换跳动。

接入方式：

1. 把已审核透明立绘保存到本目录（如 `idle-v1.webp`），附来源、授权与制作记录，不放外部热链。
2. 将清单 `status` 改为 `original`，`source` 指向 `/characters/memory-guide/idle-v1.webp`，更新 alt。
3. `states` 可分别配置 `idle / welcome / thinking / speaking / guiding / arrived`；未提供的状态回退基础立绘。角色组件不需要修改导航或相机。
4. 图片载入失败会回退到明确标记的开发预览。不能把素材错误显示成最终立绘已通过验收。
5. 检查桌面/手机缩放、透明边缘、状态切换、reduced-motion 和无网络时仍可载入，再移除预览说明。

目前预览仅有 CSS 微弱呼吸和 SVG 眨眼，以及状态标签/轻微姿态变化，不代表完成 Live2D、分层人物动画或完整人物模型。高质量最终立绘仍待资产制作与审核。未来分层动画应另定义头、眼、口、头发、手的图层基线；不能在扁平位图上用错误位置的覆盖物伪装眨眼。
