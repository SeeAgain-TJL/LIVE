# Exterior Batch 2 · 视觉精修审阅

基线 `4d9e9e0`（Batch 1.2），测试分支 `feat/planet-exterior`。本批只修改外部行星视觉与取证工具。

## 实装与取景

地表夜面保留很弱的反射，直射仍由星球和恒星决定；沿昼夜线软化，薄大气只在原壳层上按入射方向着色。岩石使用不等深度的陨坑、碎屑和侵蚀边；冰面用强弱不等的裂缝和少量分支；海面粗糙度随浅滩和细尺度纹理变化，云层随入射光变暗；气态及环绕类使用宽度与对比不同的云带和局部涡流。星环具有分区、间隙及外缘渐隐，环与球体互相投影。没有增加纹理张数、阴影贴图、全屏处理或几何层。

使用安装版 Google Chrome headless、同一 Windows 11 / Core 5 220H / Intel Graphics D3D11 机器、1600×1000 CSS 像素、设备 DPR 1.5 和生产构建。视觉取证从实际星系页面加载隔离示例，在 reduced motion 下固定相机与星球旋转，分别用光源与视线的夹角 29°（正面）、89°（侧面）、151°（背光）、61°（靠近）取景。两版使用同一坐标、种子和书签。高档各五类前后对照，共 40 张；中、低档另各拍五类近景。全尺寸 2400×1500 PNG 保存在本机；接触表只裁切和缩放 Chrome 图像。

[岩石](exterior-batch-2/visual/rocky.webp) · [海洋](exterior-batch-2/visual/ocean.webp) · [气态](exterior-batch-2/visual/gas.webp) · [冰川](exterior-batch-2/visual/ice.webp) · [星环](exterior-batch-2/visual/ringed.webp) · [中档近景](exterior-batch-2/visual/medium.webp) · [低档近景](exterior-batch-2/visual/low.webp)

50 张最终实图均取得预期的驻留档位，未出现 Chrome 控制台错误。岩石陨坑保留凹陷与局部边缘，气态纹理由规整的明暗带变为宽窄不一的层次；冰面背光能分辨裂缝，星环不同区域的透光量和球影可见。背光深海仍接近黑色，沿岸和云区可辨认；水面高光受取景角度影响，并非每张都可见。低档保留三维轮廓和昼夜关系，近景的细冰裂和云层低于高档清晰度。视觉由实图复核，最终美术判断留给用户。

## 先复测 5 颗高档

在开始材质修改前，用未改动的 `4d9e9e0` 跑了四轮隔离 Chrome。平移 **59.17 / 60.00 / 60.00 / 60.00 FPS**，p95 **16.8–16.9 ms**；缩放均约 **60 FPS**，p95 **16.9–17.0 ms**。上批第一轮约 41 FPS 的情况这四轮未复现，现有样本不支持存在持续回退，也不能确定当时低值的原因。四轮平移主画面 GPU p95 **3.0–5.2 ms**，离屏星云 **4.6–6.7 ms**。

## 性能复现

## 50 颗高档专项补测

在完整 Chrome 回归结束后，串行交替追加四组。下表均为基线 → 精修版。

| 组 | 平移 FPS | 平移 p95（ms） | 平移主画面 GPU p95（ms） | 缩放 FPS |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 31.3 → 29.0 | 50.1 → 50.2 | 5.84 → 5.27 | 30.2 → 26.9 |
| 2 | 30.9 → 30.0 | 50.1 → 50.1 | 4.90 → 3.99 | 29.3 → 30.5 |
| 3 | 27.8 → 60.0 | 66.7 → 16.8 | 6.75 → 5.03 | 27.4 → 60.0 |
| 4 | 59.6 → 57.1 | 17.2 → 17.4 | 5.19 → 6.77 | 60.0 → 60.0 |

合并原矩阵的两组，六组平移有五组平均 FPS 下降；成对差值中位数约 **−2.2 FPS**，最大退化为 **−6.6 FPS**。五组平移 p95 相同或增加 0.1–0.2 ms，另外一组出现从约 28 到 60 FPS 的大幅反转。五组主画面 GPU p95 下降、一组上升；测试显示现有帧率波动依旧明显，未测出持续的 p95 恶化，也不能宣称平均 FPS 没有回退或判定波动来源。若需把高档运动帧率作为发布门槛，建议在有窗口的 Chrome 联合采集输入、合成和 GPU 时间。保留 [专项摘要](exterior-batch-2/focus-fifty.json)及[逐帧文件](exterior-batch-2/focus-fifty.ndjson.gz)。

## 自动化与覆盖限制

lint、strict typecheck、单元测试 **48/48**、Next 生产 build、Chrome 完整回归 **30/30**（4.3 分钟）通过。专项继续验证三档切换的资源释放、优先飞往离屏目标、暂停 Worker 时可操作，以及 Worker 不可用时回退。全量 Chrome JSON 在本机 `artifacts-local/exterior-batch-2/browser-full.json`。

此处只测本机安装版 Chrome headless。真实手机、跨浏览器 GPU、长时间运行和有窗口的浏览器合成未验证。
