# 产品长期规范 · UNIVERSE OF ME

原始需求确立日期：2026-10-28。本文是长期产品约束，范围超出当前原型；当前交付状态以 `PROGRESS.md` 为准。

## V3.0 任务 A 的体验约束（2026-10-29）

在既有记忆殿堂上改善可用性：以全宽 3D 空间为中心、星球资料简洁可展开、查找和管理分组。记忆由明确操作打开，×/Escape 关闭后回到空间，不因只有一条结果自动重开。详情采用稳定的非模态阅读抽屉，长文独立滚动；编辑/删除弹窗优先处理 Escape。正文至少 16px、常用控件至少 14px，深色主题下辅助说明保持可读。

引导者保留场景左下角、短对话和少量主要操作，高级查找按需展开，阅读详情时隐藏。宇宙主页和既有存储保持兼容。后续四层探索（宇宙→星系→星球→记忆球）与跨页可拖动引导者仍是后续范围，不在任务 A 中重写实现。

## 愿景与所有权

**人生不是一条直线，而是一个不断扩张的宇宙。** 用户可自由探索、存放与回顾一生的经历。产品需要伴随用户十年、二十年乃至更久，持续增加星球与记忆。它不是宇宙背景的普通相册或日记。数据所有权属于用户，维护和升级不能导致记忆丢失。

星球名称、人生阶段、叙事均由用户决定。支持未命名草稿，禁止自动为用户生成阶段名称或虚构人生内容。

## 空间词汇

| 概念 | 含义与关系 |
| --- | --- |
| Universe 宇宙 | 用户完整人生世界，拥有星系与星球 |
| Galaxy 星系 | 成长、友情、事业、梦想等主题分类，可扩展管理 |
| Planet 星球 | 核心实体，一段用户自己定义的人生阶段 |
| Satellite 卫星 | 星球中的重要事件/记忆集合，后续扩展 |
| Memory 记忆 | 有发生时间的文字、照片、视频与图文记录，属于星球 |
| PlanetConnection 星轨 | 星球间联系，未来用于跨星球记忆旅行 |

## 视觉与体验

深黑、深蓝为基底，参考真实太空摄影与电影级探索场景。以真实空间深度、恒星、星云、各类行星为核心；不能用视频代替真实交互宇宙。星球应具备表面材质、光照、大气层、自转，可选星环；支持岩石、海洋、气态、冰冻及带环星球。

克制的半透明深色 UI，动画自然且有交互目的，阅读空间安静优雅。真实感不能损害可用性。桌面和手机均可操作；低性能设备简化像素比、面数、恒星数量和后处理，尊重系统减少动态效果。3D 不可用时仍可访问档案。

## 三个核心页面

### 3D 宇宙入口

- 拖动旋转视角，滚轮/双指缩放，星球位于不同三维坐标。
- 点击显示名称、阶段时间和简介；双击平滑飞向星球。
- 选中后进入独立记忆空间，先靠近，再过渡；支持离开档案返回宇宙和重置全景。
- 星球搜索、按年份查找覆盖该年的人生阶段、创建入口、恢复上次探索位置。
- 可选电影化开场须可跳过，不得每次强制观看。第一轮不加开场。

### 星球记忆档案

采用 **3D 星球场景 + 结构化档案页面**，不能把全部文字贴在旋转球面。

档案包含自定义名称、开始/结束日期（可持续）、所属星系、介绍、自定义封面、外观配置、创建与更新时间。

记忆支持文字日记、照片上传与展示、视频上传与播放、每条发生日期、图文混合、修改/删除、时间排序、持续追加。原始记录与多年后的感想要区分；未来「写给过去的自己」以独立感想实体关联，不能覆盖当年的内容。

### 创建与编辑星球

创建入口 → 用户输入名称（可留空为草稿）→ 时间范围 → 介绍 → 选择星系 → 类型/颜色/纹理/可选星环 → 实时预览 → 保存 → 适度诞生动画 → 新星球加入宇宙 → 可继续添加记忆。

保存后能编辑名称、外观及资料。存储失败时保留表单内容并提供明确反馈。日期必须有效，结束不得早于开始；持续阶段不同时保留结束日期。

## 探索模式

1. 自由探索：第一阶段重点，真实 3D 旋转、缩放、靠近与进入。
2. 时间旅行：先完成基础年份筛选，后续按阶段顺序旅行与时间轴导航。
3. 星系地图：整体查看主题分类、关系与星轨，留待高级阶段。

## 隐私与长期保存

所有星球默认私人；未来只分享用户指定的星球，权限可撤销、可过期。可靠账号认证，**每次服务端读取/写入都检查所有权或授权**。不可通过猜测媒体 URL 绕过权限。媒体使用私有对象、鉴权与短期授权 URL。

支持备份、恢复、完整导出文字/照片/视频及关系信息，版本迁移不得丢失已有内容。大文件考虑分片、断点续传、视频播放和缩略图生成。正式存储接入前必须明确标为本地开发方案，不能假装已接云端。

## 阶段与验收方向

| 阶段 | 范围 | 核心验收 |
| --- | --- | --- |
| 1 · 3D 基础 | Next.js、页面组件、星空、多种行星、旋转缩放、选择、飞行、进入/离开转场 | 可启动、可构建、真 3D 可操作；星球档案与最小创建入口可用 |
| 2 · 记忆功能 | 创建/编辑、详情、文字、图片/视频、持久化、搜索与时间导航 | 可持续添加回顾和编辑内容，失败不丢表单 |
| 3 · 正式使用 | 账号、权限、PostgreSQL、对象存储、安全上传访问、备份导出、性能兼容 | 越权与恢复演练通过，数据可完整迁出 |
| 4 · 高级体验 | 星系管理、星轨、时间旅行、更多外观、分享、可选 AI 整理 | 功能不破坏私人默认值、原始记录和数据所有权 |

每阶段都要构建并验证主要流程。工程必须采用 TypeScript、组件化、分离 3D 与业务、封装数据访问、处理空数据与失败。需求不等同于本轮全部实现；每轮诚实交接未完成项。
