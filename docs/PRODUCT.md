# 产品长期规范 · UNIVERSE OF ME

原始需求确立日期：2026-10-28。本文是长期产品约束，范围超出当前原型；当前交付状态以 `PROGRESS.md` 为准。

## V3.0-C3 原创角色与表演方向（2026-10-29）

VRM 实验技术可行，但用户明确否决现有 pixiv 样本的外观与程序姿态表现。下一步先做原创角色设计与精修动画制作，不继续靠调整样本骨骼角度、新按钮或话术代替人物表演。

新方向为「宇宙记忆守护者」：延续成年女性比例，精致动漫五官、自然狐耳、银蓝分层长发、深靛古风与星空融合服装；温柔聪慧、略带俏皮。参考作品只提取灵动柔和的气质，不复制人物、幼年比例或服装。完整提案见 [C3 制作包](character/README.md)，当前为文字规范，未有新美术图稿通过审核。

表演以制作好的片段为主，目标追踪、IK、LookAt、表情合成与 SpringBone 为辅。先设计自然待机、宇宙引导、召唤真实记忆球的准备/动作/缓冲/停顿/恢复，脸、眼、身体协调。无新分类、AI 或语音；现有宇宙/星系/星球/记忆、导航、CRUD 与浏览器数据原样保留。概念图、模型、表演与 runtime 逐关审核，技术测试通过不代替视觉判断。

## VRM 角色验证（2026-10-29）

V3.0-C 的 SVG 交互功能通过，角色视觉验收未通过。后续人物表现优先研究 VRM 1.0 真实骨骼路线，不继续用 CSS、位移或换图冒充自然人物动作。当前先在独立 `/guide-lab` 验证注视/转身/指引、实际相机旅行后的欢迎，以及真实记忆球飞到手骨掌心的三维交互；正式宇宙与引导者保持原样。

最终人物仍应为原创成年女性、银蓝长发、深蓝星空幻想服装。来源明确、授权允许的官方 VRM 样本可以用于技术验证，但必须明确标为非最终人物，不能算作美术验收通过。实验必须交付实际运行的逐动作截图/录屏、动作局限与性能测量；自动化检查通过不能替代用户视觉判断。实验不修改/清空任何用户档案，不接 AI/语音，也不拓展菜单或星系功能。

## V3.0 任务 A 的体验约束（2026-10-29）

在既有记忆殿堂上改善可用性：以全宽 3D 空间为中心、星球资料简洁可展开、查找和管理分组。记忆由明确操作打开，×/Escape 关闭后回到空间，不因只有一条结果自动重开。详情采用稳定的非模态阅读抽屉，长文独立滚动；编辑/删除弹窗优先处理 Escape。正文至少 16px、常用控件至少 14px，深色主题下辅助说明保持可读。

引导者保留场景左下角、短对话和少量主要操作，高级查找按需展开，阅读详情时隐藏。宇宙主页和既有存储保持兼容。后续四层探索（宇宙→星系→星球→记忆球）与跨页可拖动引导者仍是后续范围，不在任务 A 中重写实现。

## 愿景与所有权

**人生不是一条直线，而是一个不断扩张的宇宙。** 用户可自由探索、存放与回顾一生的经历。产品需要伴随用户十年、二十年乃至更久，持续增加星球与记忆。它不是宇宙背景的普通相册或日记。数据所有权属于用户，维护和升级不能导致记忆丢失。

星球名称、人生阶段、叙事均由用户决定。支持未命名草稿，禁止自动为用户生成阶段名称或虚构人生内容。

## 空间词汇

| 概念 | 含义与关系 |
| --- | --- |
| Universe 宇宙 | 用户完整人生世界，拥有星系与星球 |
| Galaxy 星系 | 成长、友情、事业、梦想等主题分类，可扩展管理 |
| Planet 星球 | 核心实体，一段用户自己定义的人生阶段 |
| Satellite 卫星 | 星球中的重要事件/记忆集合，后续扩展 |
| Memory 记忆 | 有发生时间的文字、照片、视频与图文记录，属于星球 |
| PlanetConnection 星轨 | 星球间联系，未来用于跨星球记忆旅行 |

## 视觉与体验

深黑、深蓝为基底，参考真实太空摄影与电影级探索场景。以真实空间深度、恒星、星云、各类行星为核心；不能用视频代替真实交互宇宙。星球应具备表面材质、光照、大气层、自转，可选星环；支持岩石、海洋、气态、冰冻及带环星球。

克制的半透明深色 UI，动画自然且有交互目的，阅读空间安静优雅。真实感不能损害可用性。桌面和手机均可操作；低性能设备简化像素比、面数、恒星数量和后处理，尊重系统减少动态效果。3D 不可用时仍可访问档案。

## 三个核心页面

### 3D 宇宙入口

- 拖动旋转视角，滚轮/双指缩放，星球位于不同三维坐标。
- V3.0-B2 起单击/轻触 3D 星球即平滑靠近并自动进入记忆空间，不再要求第二次确认；悬停显示简要信息，左侧列表独立查看与编辑资料。
- 飞行与转场支持 Escape 取消，忽略拖动、多指与重复点击；离开档案回到所属星系及进入前的探索视角，仍可重置全景。
- 星球搜索、按年份查找覆盖该年的人生阶段、创建入口、恢复上次探索位置。
- 可选电影化开场须可跳过，不得每次强制观看。第一轮不加开场。

### 星球记忆档案

采用 **3D 星球场景 + 结构化档案页面**，不能把全部文字贴在旋转球面。

档案包含自定义名称、开始/结束日期（可持续）、所属星系、介绍、自定义封面、外观配置、创建与更新时间。

记忆支持文字日记、照片上传与展示、视频上传与播放、每条发生日期、图文混合、修改/删除、时间排序、持续追加。原始记录与多年后的感想要区分；未来「写给过去的自己」以独立感想实体关联，不能覆盖当年的内容。

### 创建与编辑星球

创建入口 → 用户输入名称（可留空为草稿）→ 时间范围 → 介绍 → 选择星系 → 类型/颜色/纹理/可选星环 → 实时预览 → 保存 → 适度诞生动画 → 新星球加入宇宙 → 可继续添加记忆。

保存后能编辑名称、外观及资料。存储失败时保留表单内容并提供明确反馈。日期必须有效，结束不得早于开始；持续阶段不同时保留结束日期。

## 探索模式

1. 自由探索：第一阶段重点，真实 3D 旋转、缩放、靠近与进入。
2. 时间旅行：先完成基础年份筛选，后续按阶段顺序旅行与时间轴导航。
3. 星系地图：V3.0-B1 提供宇宙星系入口及所属星球层；关系与星轨仍留待高级阶段。

## V3.0-B1 体验约定

默认路径为宇宙 → 星系 → 星球 → 记忆球。宇宙先展示星系，点击飞近进入；星系复用原有星球渲染、创建/编辑与进入流程，记忆空间保留独立阅读和全部 CRUD。已有无归属星球自动归入「未分类星系」，不替用户命名、不改写原始人生记录。星系骨架不等于完整星系管理，本轮没有星系增删改。

整个产品只有一位原创银蓝长发、深蓝幻想服装的成年动漫记忆引导者，默认左下角，以 2D SVG 半身形象常驻。自己探索后保持安静，按需展开目的地；可以引导前往真实星系/星球，在星球内调用真实搜索、年份、照片/视频、最近与随机记忆。支持收起、隐藏、左右拖动吸附与键盘切边；预览和阅读时紧凑，不遮挡主要按钮。状态在本次客户端跨页保留，刷新恢复默认。

不使用语音、AI、3D 角色骨骼或复杂剧情；不上传私人内容到模型服务。角色可定制名称、完整立绘资产与全局二维自由拖动后续单独设计。减少动态效果偏好与非 WebGL 的直接链接继续可用。

## V3.0-B2 进出体验约定

沿用既有宇宙、星系、星球和记忆布局，单击星球立即进入一个可取消的导航任务。镜头从用户当前所在方向接近，保持表面、光照和大气可见，不穿入球体；到达外部安全距离后淡出并进入既有记忆殿堂。飞行中不重复启动导航，拖动、长按和双指操作不视作进入。Escape 在飞行及待导航的渐变期间都能取消，并恢复出发视角。减少动态效果时缩短飞行和转场，省略中途提示。

返回所属星系先淡出记忆空间，再从目标星球外部恢复出发视角，不强制回到宇宙总览。可选的标签页会话记录支持记忆页面刷新后的返回；直接 URL、损坏记录或星球改变归属时回退到正确星系的有效镜头书签/全景。关闭 WebGL 后仍能用列表和档案按钮直接访问。

同一全局引导者保留跨页状态，按开始、接近和抵达触发短句；可在展开面板关闭自动飞行/抵达提示，用户主动使用的查找仍可用。此偏好仅在当前客户端路由会话保留，刷新恢复默认。不修改任何人生内容或存储 schema。

## 隐私与长期保存

V3.0-C 在不改变层级/档案的前提下，让人物默认独立存在，鼠标/触屏二维拖动后左右停靠，位置/显示/自动台词偏好刷新保留。独立对话提供自由探索、真实目的地、全局记忆查找、最近记忆与返回上一级；长列表分批显示。导航短句随实际事件触发，可关闭；阅读与表单优先，人物临时紧凑或让出交互。六状态资产接口已实现，但当前 SVG 明示为开发预览，最终高质量原创成年角色立绘仍待制作，不把占位素材称为最终形象。此约定取代 B1/B2 中引导 UI「刷新恢复默认」的旧范围，不更改人生档案 schema。

所有星球默认私人；未来只分享用户指定的星球，权限可撤销、可过期。可靠账号认证，**每次服务端读取/写入都检查所有权或授权**。不可通过猜测媒体 URL 绕过权限。媒体使用私有对象、鉴权与短期授权 URL。

支持备份、恢复、完整导出文字/照片/视频及关系信息，版本迁移不得丢失已有内容。大文件考虑分片、断点续传、视频播放和缩略图生成。正式存储接入前必须明确标为本地开发方案，不能假装已接云端。

## 阶段与验收方向

| 阶段 | 范围 | 核心验收 |
| --- | --- | --- |
| 1 · 3D 基础 | Next.js、页面组件、星空、多种行星、旋转缩放、选择、飞行、进入/离开转场 | 可启动、可构建、真 3D 可操作；星球档案与最小创建入口可用 |
| 2 · 记忆功能 | 创建/编辑、详情、文字、图片/视频、持久化、搜索与时间导航 | 可持续添加回顾和编辑内容，失败不丢表单 |
| 3 · 正式使用 | 账号、权限、PostgreSQL、对象存储、安全上传访问、备份导出、性能兼容 | 越权与恢复演练通过，数据可完整迁出 |
| 4 · 高级体验 | 星系管理、星轨、时间旅行、更多外观、分享、可选 AI 整理 | 功能不破坏私人默认值、原始记录和数据所有权 |

每阶段都要构建并验证主要流程。工程必须采用 TypeScript、组件化、分离 3D 与业务、封装数据访问、处理空数据与失败。需求不等同于本轮全部实现；每轮诚实交接未完成项。
