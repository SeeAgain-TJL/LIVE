# 星球视觉库 V1 · 资产与验收

预览：生产构建启动后访问 `/planet-visual-library`，或在星球编辑器打开「浏览星球视觉库」。展厅没有档案 Provider，只展示样例。12 项可以应用到已有五类外观；只复用原有字段，不填写人生阶段名称、介绍或记忆。

| 外观 | 离线原料和处理 |
| --- | --- |
| 赤色荒原星 | Mars 地貌图；校色区分红尘、暗岩和撞击盆地。起伏来自影像强度，非实测高程。 |
| 远古岩层星 | LRO/LROC 表面和 LRO/LOLA 高程；使用真实撞击盆地与高程，降低暖色。 |
| 翡翠海洋星 | Earth 海岸掩模、色图和独立云图；经纬扭曲、翡翠浅海、分散群陆。 |
| 深蓝汪洋星 | 同一来源，使用不同海岸映射、局部淹没和高纬度云层权重；全球海洋为主。 |
| 极寒冰川星 | Voyager Europa 清理后影像；分离蓝裂谷与冷色冰原，粗糙度和起伏为影像衍生。 |
| 水晶寒霜星 | Ganymede 和 Europa 影像融合；冷白霜面、青蓝区和更低粗糙度。没有独立折射冰晶模型。 |
| 苍穹风暴星 | Jupiter 云图保留真实大尺度云带和风暴形态；暖灰云顶调色。 |
| 深蓝气态星 | Neptune 地图与 Don Davis 的海王星插画融合；插画是想象材质，不能称为观测。 |
| 金辉星环星 | Saturn 云图及其星环透明度剖面；共享同一剖面渲染环隙、星环投影与星球遮挡。 |
| 暗夜星环星 | Neptune 插画、Saturn 云带与星环剖面；断续环弧，加一批手工布置的低面数碎片。未制作可独立访问的卫星。 |
| 紫雾幻境星 | Venus 云顶地图重映射到紫灰；薄雾由现有大气壳表达。 |
| 翠绿生命星 | Earth 色图、海岸掩模及云图独立重组；只处理轨道外观。 |

熔岩裂谷星、极光寒霜星、沙海环带星、金属荒原星仍为候选，目录给出缺失的资产或实机验证。它们不进入预设选择，不提供替代占位。

[资产清单](assets.json) 记录每个原始来源、原文件 SHA-256、署名、许可或使用条款，以及每个派生包的尺寸和校验和。Solar System Scope / INOVE 的相关原图与其改编部分按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 署名并标记修改；来源为 [Solar System Scope](https://www.solarsystemscope.com/textures/)。月面原料来自 [NASA SVS CGI Moon Kit / Ernie Wright](https://svs.gsfc.nasa.gov/4720/)，遵循 [NASA 媒体使用说明](https://www.nasa.gov/nasa-brand-center/images-and-media/)。冰冻原料来自 [JPL/Caltech/USGS 的木星卫星地图](https://maps.jpl.nasa.gov/tmaps/jupiter.html)，海王星插画由 Don Davis 创作、由 [JPL 地图项目](https://maps.jpl.nasa.gov/tmaps/neptune.html) 发布；按 [JPL 图像使用政策](https://www.jpl.nasa.gov/jpl-image-use-policy/) 署名，不暗示机构或作者背书。上述使用条款适用于各自来源，不能将整库标为单一通用许可。

离线合成使用现有 sharp 和 Node，未引入 Blender 工程或外部模型：沿用原有球体 UV 和模型，运行时只加载目标档的本地包，在现有 Worker 解码后交回原调度器。每包输出已有的颜色和材质两张 GPU 纹理。低档海洋将云合入颜色，高、中档在相同地理位置使用现有透明云层。星环剖面在离线阶段提取为常量，不另占 GPU 贴图槽。

复现：按清单下载原图，将文件命名为对应来源键（如 `mars`、`moonHeight`），放入 `artifacts-local/planet-visual-library-v1/source/`。运行 `node scripts/prepare-planet-visual-library.mjs` 后运行 `npm.cmd test`。部署只包含生成的 36 包、署名清单和运行代码；不联网请求原图。

真实 Chrome 证据：[展厅画面](visual/gallery.jpg) · [五角度联系表](visual/angles.jpg) · [三档近景联系表](visual/tiers.jpg) · [截图索引与错误日志](visual/capture.json)。联系表仅缩放和拼接来自真实 WebGL 画布的截图。84 张原始画布 PNG 和完整展厅截图位于本地 `artifacts-local/planet-visual-library-v1/gallery-r3/`；可用 `node scripts/capture-planet-visual-library.mjs <新标签>` 重新采集（`EXTERIOR_AFTER_URL` 指向候选生产服务）。

### 性能方法

同一台 Windows / Intel 核显，同一生产构建配置。真实 Chrome 通道、无头模式、1600×1000、浏览器 DPR 1.5；低档的画布 DPR 仍由实际预算限制。对比基线 `243eca2` 与 V1 的同一档案夹具、相机和输入，交替执行先后。基线用相同的类型、尺寸、颜色和种子生成旧贴图；候选将对应种子解析为预设。5 颗覆盖五类，20/50 颗复用 12 种预设；此结果代表重复使用预设的场景，不外推到 50 套不同的资源。每次新开浏览器上下文并禁用 HTTP 缓存；合成档案不代表用户数据。

首次可交互指相机控制就绪并实际绘制首帧；贴图就绪指初始镜头内 LOD 当前请求的目标都已驻留，不含不可见星球和未被请求的高档。另测静止、右键平移、双向滚轮缩放、换档往返、进入和返回档案；资源探针同时记录 GPU/CPU 帧时间、draw call、CPU 缓存与驻留贴图估算。GPU 查询可用时使用 WebGL timer query；数值含浏览器/系统抖动，不将单轮结果当成稳定归因。

复现命令（基线和候选使用独立生产服务）：

```powershell
$env:EXTERIOR_REVIEW_BATCH='library-v1'
$env:EXTERIOR_LOD_MODE='matrix-once'
$env:EXTERIOR_BEFORE_URL='http://127.0.0.1:3355'
$env:EXTERIOR_AFTER_URL='http://127.0.0.1:3359'
node scripts/benchmark-exterior-lod.mjs matrix-new
```

### 复测与剩余问题

对首轮慢帧明显的三组追加两轮，交换基线和候选的顺序，共 12 个用例。将首轮合在一起看，结果如下（FPS / p95 毫秒的范围）：

| 场景 | 基线 | V1 |
| --- | --- | --- |
| 20 颗高档缩放 | 58.9–60.0 / 16.9 | 42.2–60.0 / 16.8–49.9 |
| 50 颗中档平移 | 58.3–60.0 / 16.9–17.1 | 44.0–60.0 / 16.9–33.5 |
| 50 颗低档平移 | 57.9–60.0 / 16.9 | 54.0–59.6 / 16.9–33.4 |

20 颗高档和 50 颗中档各有一轮达到约 60 FPS，也各有一次复测仍低于基线。50 颗中档慢轮的主渲染 GPU p95 升到 7.4–8.1 ms，平稳轮为 4.0 ms，基线为 3.4–4.8 ms；绘制数只增加约 1 项，CPU 帧时没有同比恶化。这些数据提示主渲染成本或核显调度波动，无法隔离到某个材质。保留为性能风险，未认定为无回退；后续若继续，优先隔离有／无星环剖面的主渲染 GPU 对照，并控制后台负载。[复测报告](recheck-r2.json) · [复测原始数据](recheck-r2.ndjson.gz)。

验证命令：`npm.cmd run lint`、`npm.cmd run typecheck`、`npm.cmd test`（50 项）、`npm.cmd run build` 均通过。生产模式全量 Chrome 回归 33 项通过；保留窄屏样例标识后重新构建，V1 专项 3 项再次通过。原始 Chrome 日志位于本地 `artifacts-local/planet-visual-library-v1/`。
