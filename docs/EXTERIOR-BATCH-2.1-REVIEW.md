# Exterior Batch 2.1 · 地貌与材质审阅

基线：`713fe73`（Batch 2）。本轮只调整外部星球地貌、星环的渲染与审阅工具。

## 材质取舍

- 冰冻：用有限长度、带局部朝向的冰流盆地替换全局等值线。每条冰流沿自身切平面弯曲，宽度从积雪区向末端收窄；冰缘堆积、错阶、断续剪切带和顺流纹理有不同高度与粗糙度。盆地之间保留较平缓的冰原，蓝冰只在部分流动或受压地带露出。第一版实图显示色块过于整齐，第二版在边缘和内部加入与流向一致的形态变化。
- 气态：用固定种子生成宽度与明暗不一的纬向云带。有限范围的椭圆风暴旋转同一组云带与细丝，极区逐渐脱离纬带；仍然是静态材质，没有流体模拟。
- 岩石：调整原撞击点的坑底、不同高度的台阶、侵蚀坑缘和大坑内部峰体，让高度与岩层颜色共同描述地貌。较高地带露出弯曲山脊。起伏用现有 bump 通道表现，球面轮廓没有位移。
- 带环：不等宽的主间隙和窄缝隔开数段不同密度的环；细环间距随半径变化，亚像素细节渐隐。环影和环面继续共用径向密度。最终版仅在直射光线与环带相交时计算球面的环影密度，导数在条件外求值；球影保留。近处颗粒只是明度变化，没有增加颗粒几何。
- 海洋：浅海盆地、群岛与赭色高地取代大块绿陆地与对称极冠；沿岸浅滩和云锋各有独立形状。粗糙度随水域与天气变化，沿用 Three.js 高光，无额外反射贴图。

复用项目现有 MIT 许可的 Three.js [`MeshStandardMaterial`](https://threejs.org/docs/pages/MeshStandardMaterial.html)，保留其 PBR 光照，继续将高度、粗糙度和云覆盖打包在同一线性 RGBA8 图。NASA 的 [Europa 断层和冰原](https://science.nasa.gov/science-research/landscapes-and-features-of-europa/)、[Juno 云带与湍流](https://science.nasa.gov/photojournal/juno-sees-turbulence-in-jupiters-atmosphere/)、[LRO 陨坑台阶](https://science.nasa.gov/image-detail/aristarchus-crater-lro-web-1/) 和 [Cassini 星环波纹](https://science.nasa.gov/resource/rings-and-waves/) 仅作形态参考。没有复制外部纹理、图像、着色器或引入新依赖。两张纹理、各档分辨率、网格预算、Worker 调度、缓存与 LOD 策略均沿用 Batch 1.2。
