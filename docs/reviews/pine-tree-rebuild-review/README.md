# Pine Forest · 连续漫游与记忆

[连续漫游录屏（WebM）](https://github.com/SeeAgain-TJL/LIVE/releases/download/pine-tree-rebuild-review-20261105/pine-tree-rebuild-walk.webm) · [画面和实测](../pine-tree-rebuild/README.md)

来自生产 Chrome 的连续录屏，1440×900，50.52 秒。Playwright 通过浏览器真实键盘和鼠标事件从出生点沿干岸走到记忆球，按 E 进入阅读，查看照片和视频，按 Escape 回到行走，再转头和侧移。没有瞬移、替换背景或拼接镜头。档案和附件是隔离测试夹具，无私人记忆或媒体。视频为 25 FPS 的录制文件，性能数据使用另一次未录制的漫游。
