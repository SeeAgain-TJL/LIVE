# Pine Forest · 林缘连续性收口

外延地面从原求值地形的 66,049 个顶点中读取边界，按实际边界高度和 UV 接续；原边界下压仅 0.035m，不修改原地形或导航。外延与原地表共用同一个 PBR 材质和光照场，不再用单色基底模拟源地面。

保留上一版 951 个源轮廓补景站位，逐一垂直求交外延地面三角形，重算根部高程。另从图集 alpha 找真实树根，卡片围绕根部随视角倾斜，避免整棵树绕中心转动时悬空。站位求交误差小于 0.00001m；这只验证落点，不等于逐棵人工巡视。

阶段验证：源数据与地面求交断言、lint、typecheck、生产构建、约 41m 抬高视角截图通过。未增加可行走区域，未增加补景树数量。地面视角、全林俯瞰与连续漫游统一放在最终验收。运行资产为新 `template-edge/` 增量。
