# Exterior Batch 1.1 · 验收记录

日期：2026-11-04。基线：Batch 1 提交 `2953935`；优化后：本记录所在的 `feat/planet-exterior` 交付提交。Batch 1.1 的主要收益是降低主线程阻塞。50 颗高档的完整贴图仍需约 16 秒，平移也没有达到稳定 60 FPS。

## 取样口径

Windows 11，Intel Core 5 220H，约 15.55 GiB RAM，Intel Graphics / ANGLE D3D11（驱动 32.0.101.7076），安装版 Google Chrome 156.0.8078.80（Playwright headless），1600×1000 CSS 视口、设备 DPR 1.5。使用生产服务 3321，每例新浏览器上下文、禁用 HTTP 缓存、固定种子与对应规模的相同相机书签。数据为明确标注的外观压力样本，不属于用户经历；测试前后档案原文相同。

冷进入计时从导航到首个已报告对应档位且完整贴图就绪的采样，再留 100 ms 供绘制；基线同步烘焙，使用首个对应档位的渲染指标作为代理。这一指标包括页面启动和采样等待，不等于首帧或首个可交互时间。就绪后预热 1.8 秒，静止采样 4 秒，再采八次右键平移及阻尼。FPS 用 rAF 平均帧间隔计算；CPU 指 rAF 回调执行，GPU 计时来自 WebGL timer query，两者均不等于完整帧间隔。

## FPS 波动与资源限制

- 基线首轮 5 颗高档静止 31.7 FPS、GPU p95 35.8 ms，第二轮静止 60 FPS、GPU p95 9.9 ms，rAF CPU p95 两轮约 2.8 / 2.7 ms。两轮整机 CPU 平均分别 63.7% / 23.8%，起始可用内存约 0.42 / 3.98 GiB；首轮 20 颗也出现类似的 GPU 耗时抬升。这些数据支持 GPU 执行或调度随系统负载变化的解释，整机指标涵盖整个测试案例，无法定位后台进程或断言唯一原因。
- 本地 5 颗高档静止 trace 中，基线低帧率轮最长渲染线程 `FireAnimationFrame` 约 5.3 ms，最终两轮约 5.1 / 6.3 ms，这四份 trace 均无已记录的 GC 事件；最终第二轮另有 134.6 ms 的 `BeginMainFrame`，其中调度事件 107.7 ms。现有 trace 不支持将持续掉帧归因于同步 JS 或 GC，也不足以确定每次调度停顿的来源。
- 最终 50 颗高档平移两轮 rAF CPU p95 为 7.2 / 6.0 ms、GPU p95 为 15.5 / 14.1 ms，采样内没有 ≥50 ms 主线程长任务。其高档 151 次 draw、约 89 万三角形和 101 张渲染器计数纹理与基线一致；在约 16.7 ms 的帧预算下，GPU 工作与合成/调度余量有限。中、低档个别平移样本同样掉帧；这两组顺序采样未隔离所有系统负载，仍需独立复测。
- 直接 WebGL 探针与渲染器统计口径不同。修复前，5 颗高档的活跃 GL buffer 从 129 累增到 210；修复后，在 5 / 20 / 50 颗上三次档位循环内，同档的纹理、缓冲、程序、几何和材质计数稳定。高档稳定 GL buffer 数分别 129 / 338 / 626；离开星系后旧上下文丢失、缓冲数为 0，另一个上下文属于宇宙主页。此结果只覆盖短时换档、取消和卸载。
- 32 MiB 只限 CPU 缓存。50 颗高档样本的活跃贴图源像素约 200 MiB；含 mip 的两张 RGBA8 图每颗理论约 5.33 MiB，合计约 267 MiB，未测实际显存。资源测试中 50 颗高档 GC 后 JS heap 样本约 232–283 MiB，返回主页后约 46 MiB；不能把缓存上限视为进程或显存上限。

## 视觉、范围与证据

逐对查看了安装版 Chrome 的六张 2400×1500 实图。5 颗图中五类外观、星环间隙及投影、昼夜交界与海洋云层可辨；20、50 颗图中排列、星环、轨道和星点保持同一构图，未见贴图缺失或明显视觉回归。按整张图的解码 RGB 比较，5 / 20 / 50 颗分别有 **98.23% / 98.66% / 98.27%** 的像素完全相同；截图未冻结自转、云层及其他动态效果，整屏像素差不能等同于材质差。五类 × 三档 × albedo/surface 的 **30 组**贴图以 SHA-256 验证，整图烘焙和分片续跑均与基线逐字节一致。这是已就绪场景的一致性检查，首载期间会暂时显示底色球；没有把高档全景当作全档位近景或美术终验。

原图位于忽略目录 `artifacts-local/exterior-batch-1.1/{before,after}/`，每侧有 `5-high-r1.png`、`20-high-r1.png`、`50-high-r1.png`；5 颗静止 trace 位于同目录的 `5-high-r{1,2}-trace.json`。基线唯一记录的网络错误为 `/favicon.ico` 404，最终矩阵没有记录网络错误或 pageerror；生产回归另行断言图标返回 200。

复现时，用独立基线工作区构建 `2953935`，先后将基线和当前生产构建运行于 3321，然后从本分支运行 `node scripts/benchmark-exterior.mjs <新记录名>`。可用 `EXTERIOR_BENCH_URL` 指定其它生产端口。每次选新记录名，保留已有原始样本。当前构建可运行 `node scripts/check-exterior-resources.mjs`（固定端口 3321）和 `node scripts/verify-exterior-pixels.mjs`，两者会写入对应 JSON，复测前应保留原始证据。完整回归按 `npm.cmd run build` 后 `npm.cmd run test:e2e` 执行，使用独立端口 3100。

收尾复跑：lint、strict typecheck、Node 单元测试 **47/47**、生产 build、完整 Chrome 回归 **29/29**（5.2 分钟）通过。外观浏览器专项覆盖多轮换档、缓存命中、图标 200、禁用 Worker 后分片及快速取消；像素复核重新生成的 JSON 与原文件相同。本轮压力和资源矩阵以原始采样和 trace 为证据，未重新跑整套压力矩阵。

长期运行、真实手机 GPU、其他浏览器及冷启动首次可交互时间未验证。50 颗高档完整贴图、平移掉帧和大场景换档缓存未命中仍是待解决项。
