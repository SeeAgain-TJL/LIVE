## 1. 当前造型锁定与旧规范失效项

- 脸：精致柔和的动漫五官、蓝紫系眼睛、清晰上眼睑、小鼻与自然嘴唇；保留效果图成熟而温柔的气质。不套通用 VRoid 脸，不擅自改瞳色为旧方案的灰蓝/金环。
- 发：银白冠顶与脸侧亮面，向冷蓝紫中后段过渡；薄层侧分刘海、耳前/颊侧束、长后发与细小编束/饰链分开。渐变不做平均灰色，发型不简化成一整块披肩。
- 狐耳：一对浅色自然毛绒长耳，内侧浅暖灰粉、外侧银蓝；耳根与头颅有体积连接。不能新增外露的人耳形成四耳。
- 狐尾：**保留一条大型银蓝渐变蓬松尾巴**，以侧视图确认单尾结构、效果图确认毛量气质；轮廓里的多簇毛不是多条尾巴。尾根具体位置尚被遮挡，需要补图。
- 服装：露肩深蓝星空礼服、领部装饰、浅色半透明垂袖、多层前开长裙、金色星轨/星芒饰件、蓝色晶体和高跟鞋；复杂饰品后置，不把礼服改回交领长衣。
- 旧方案的 7.2 头身、1.68 m、13 cm 耳长、短靴、无尾巴、偏心双弧扣等不再强制套用。比例从当前图稿规范化，绝对身高只作为后续尺度标定，不影响造型还原。

## 2. 已完成的比例对齐与其局限

从设定板裁出三个视角，以「头发冠顶，不含狐耳」和「鞋底接地，不含拖尾」作两个锚点，只做等比缩放和位移。没有透视变换、肢体拉伸或生成补画。各视角头部高度和鞋底人工估计均写入 JSON，可复查。

正面原图冠顶约 y=61、下巴约 y=148、鞋底约 y=695；按发冠顶到下巴估算约 **7.3 个头长（含鞋高度、非裸头/赤足测量）**。这只能作为对照起点，不能机械指定裸身体型为 7.3 头身。真实建模需要独立的头颅、赤足脚底和高跟鞋结构。

定义检查坐标 u = (原图 y − 正面冠顶 y) / (正面鞋底 y − 正面冠顶 y)。左右宽度与纵向长度同时等比处理，不能把眼线、腰线分别缩放凑齐。

| --- | --- | --- |
| 发冠顶 | 0.000 | 全视角统一；它不是裸颅顶，发厚度需单独画 |
| 眼线 | 0.084 | 前/侧同高；背面只辅助投影，不虚构眼睛位置 |
| 下巴 | 0.137 | 前/侧同高，需中性头姿，不能沿用效果图倾头姿态 |
| 肩点 | 0.188 | 前/后锁定左右肩峰；发袖遮挡处待裸肩结构确认 |
| 腰 | 0.322 | 目前按腰饰附近估计，需区分饰件中心与真实腰线 |
| 髋 | 0.440 | 推定线，必须补结构图；不把短内裙下缘当骨盆 |
| 膝 | 0.661 | 推定线，部分遮挡；前后和侧面确认膝关节中心 |

狐耳尖、狐耳根、眉、鼻底、唇线、锁骨、肘、腕、指尖、髋骨、尾根、脚跟与足尖还需在重绘图逐点标定。手臂姿态在侧图和前后图不同，不能直接把腕线差异归因为身体比例差异。原图裁切中存在相邻视角的衣摆/毛发重叠，保留证据但不采为当前视角结构。

## 5. G2.1 基础人物制作范围与验收

收到具备细节建模能力的工具/制作流程后，分两次视觉检查，不等全套饰品做好才看脸：

- **第一检查：头部。** 真实可编辑头颅/脸部网格、独立眼球和眼睑、眉睫、唇、银蓝分束发型、一对有厚度的狐耳；中性灰与基础色各一版。主要发饰可简化，但不能遮住脸的错误。交付正、左右侧、后、3/4 与真实 360° 头部转台。
- **第二检查：全身基础。** 统一身体比例、真实手脚、同版礼服基础轮廓和单条狐尾；先减少金链、宝石、流苏、细碎星纹和复杂透明层，不减少脸/眼/发/耳体积。尾根、发肩、袖腋无明显穿插。没有复杂动画/网站集成。

交付 `.blend`（可编辑 mesh、UV、材质、发束、耳尾与衣片分别命名，不只有贴图平面）、自包含 `.glb`、贴图、正/侧/背 1080p 静帧、12–16 s 的无剪辑 360° 转台和使用说明。GLB 用于静态查看；VRM 与复杂表情/骨架后续单独验收，不强行把未完成绑定的 GLB 改后缀称 VRM。

转台相机固定焦距和高度，人物或相机真实转一圈，无大幅风、景深、光效、剪辑遮挡；另提供头部近景。正背正交投影对应规范图，侧面必须看到鼻唇下颏和后脑体积。用户依据这些实物判断还原度，文件存在或测试通过不是视觉合格。
