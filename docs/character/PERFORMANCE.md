# C3 · 三段动画文字分镜与表演规范

**表演设计 v0.1；以下时间为制作目标，不是已播放或测得的动作。尚无分镜绘图、精修片段或新样片。** 与 [美术设定](ART-DIRECTION.md) 和 [生产规范](PRODUCTION.md) 一起交付动画师。

## 表演共识

她的注意力应能被看见：眼球先找到目标，头和胸廓随后，身体完成决定后手才行动。肘、腕、手指的动作有先后，不像机械臂同时到位。动作幅度小，但关键停顿清楚；身体不能永远正面朝用户而只转眼睛。

动作顺序以动画师制作的片段、接续姿态和事件点为主。程序负责适配实际目标与可取消导航，不能用几组常量手臂角度替代三段完整表演。参考姿态、镜头、帧数表、肢体弧线和曲线源文件一起交付。

默认以 30 fps 制作和审片；运行时按时间采样，不能假设设备恒定 30/60 fps。角色原点不随大尺度宇宙坐标直接移动，实验局部舞台统一以米为单位。主镜头采用眼高附近的 3/4 中全景；表演审片另录脸/手近景和侧面，不靠剪辑藏动作跳变。

## A · 自然待机

基础片段 `idle_breathe_A` 约 12 s；另做 `idle_weight_B` 约 9 s、`idle_observe_C` 约 11 s。不同片段有一致的可接续姿态，平静间隔后才切换，不能靠每轮随机加速制造自然感。

| 时间 / 阶段 | 身体、脸与视线 | 头发衣物 / 镜头 / 制作检查 |
| --- | --- | --- |
| 0–1.2 s · 安定 | 延续上一状态的重心，肩肘放松；E01，视线落在用户附近，不死盯镜头 | 先消除上一个动作的摆动；镜头固定，首帧不能强行回到绑定姿态 |
| 1.2–3.6 s · 吸气 | 胸廓小幅展开，腹部/肩线不同相位；手指保持自然弧度 | 刘海和衣料仅有微弱跟随；不能整体缩放人物作为呼吸 |
| 3.6–5.8 s · 呼气 | 胸肩缓慢回落，颈部保持支撑；允许一次自然眨眼 | 袖片先随手臂回落再安定；无周期性机械摆动 |
| 5.8–7.5 s · 准备换重心 | 目光短暂移向附近，骨盆开始微移；支撑腿稳定，非支撑腿膝稍松 | 脚掌不滑，头部对骨盆位移有补偿，长发延迟响应 |
| 7.5–8.8 s · 重心落定 | 肩线反向平衡，呼气末停顿；不做全身左右钟摆 | 裙摆一次衰减，腰扣不过度晃动 |
| 8.8–10.4 s · 安静停留 | E01，无必须发生的手势；偶尔小幅视线调整 | 留白是表演的一部分，不每秒添加动作 |
| 10.4–12 s · 接续 | 回到允许衔接的姿态或稳定的另一侧重心 | 首尾姿态和速度连续；下一段选择兼容站姿，不能硬跨脚位 |

呼吸基本周期可在约 4.5–6 s，眨眼间隔在约 3–7 s 内有限随机，单次约 0.12–0.22 s，闭合快于睁开；数值仅为调试起点。注意力转移时可安排一次眨眼，托球接触前后约 0.25 s 保持视觉连续。随机眨眼调度可以程序化，呼吸、重心与身体微动仍来自精修动画。暂停或后台恢复不能一次补播所有错过的眨眼。

待机至少审看连续 60 s：不能一眼看到固定重复节奏、脚底漂移、发束积累振荡、眼皮穿眼或呼吸牵动整个衣裙。Reduced-motion 下使用安定姿态、停止重心循环和明显物理摆动，保留低幅必要反馈。

## B · 宇宙引导

预制片段：`guide_prepare_L/R`、`guide_point_L/R`、`guide_hold`、`guide_arrive`、`guide_recover`，另备需要转步的 90°/180° 版本。下表假定目标位于角色右前方、无需迈大步；左右目标应制作或人工修正镜像版本，不能自动镜像非对称衣物与表情就直接交付。

| 时间 / 阶段 | 演员与表情 | 视线、真实目标与相机 | 事件与审核点 |
| --- | --- | --- | --- |
| 0–0.25 s · 注意 | E01 → E02，暂不抬手 | 眼球先看实际 Planet 位置 | 接收带目标 ID 和任务 ID 的请求；无目标不表演出发 |
| 0.25–0.7 s · 准备 | 头转向目标，胸廓随后，支撑腿调整；近侧耳轻转 | 眼/头不瞬间到极限；相机尚未飞行 | `attention`；背后目标须选择转步片段而非扭断脖子 |
| 0.7–1.5 s · 主动作 | 肩先带动上臂，肘展开，腕和手指最后形成柔和指引；E03 专注 | 目光仍在星球；手掌半开，不僵直戳指 | `pointing`；手不穿袖、胸或头发，脚位不漂 |
| 1.5–1.85 s · 缓冲 / 停顿 | 手势减速，肘略回收；稳定约 0.2 s | 指向与目标方向一致；相机保持完整人物与目标可读 | authored `point_ready` 标记 + 有效目标/实际手势稳定共同触发导航 |
| 1.85 s–实际抵达 · 旅行 | 转入 `guide_hold`，手势稍降低但保留方向，呼吸自然；不循环挥手 | **实际相机任务开始**；演员 gaze/指向追踪有限微调，不跟随所有相机抖动 | `guiding`；旅行时长由真实镜头决定，不用固定定时器假报到达 |
| 到达后 0–0.45 s · 缓冲 | 身体先稳定，眼睛回到用户，头再跟回 | 收到当前任务真实 `camera_arrived` | `arrived`；若镜头未到达，继续稳定 hold，不能先欢迎 |
| 到达后 0.45–1.5 s · 收势 | 肘下落，掌心转为邀请姿态，E06；微点头一次 | 角色面向用户，目标星球仍在构图内 | `guide_arrive`；不要同时挥手、点头、眨单眼 |
| 到达后 1.5–2.5 s · 恢复 | 手归位，肩颈放松，E06 → E01 | 转回允许自主探索的相机状态 | `guide_recover` → `idle`，结束速度与待机匹配 |

相机旅行与人物在不同空间层时，先定义演员舞台到世界目标的方向投影及有效角域；不能把距离数千单位的星球坐标直接传给手 IK。角色不要随镜头急转而瞬时旋转。目标在身后且空间不允许转步时，先选择合适舞台朝向或重构图，不强行越限。

取消：任意非完成阶段接收当前 run 的取消，取消相机任务并淡出到与当前姿态兼容的收势片段；球/档案数据不变。模型卸载或目标失效时立即释放任务，不等动画。迟到的到达事件不得重新唤起动作。动作中新增请求沿用现有防重复策略，不排队积累陈旧旅行。

## C · 召唤真实记忆球

预制片段：`summon_notice`、`summon_reach`、`summon_wait`、`summon_catch`、`summon_present`、`summon_release`。默认左手承接，右手仅在展示时轻引导视线；不让两臂同时做复杂无目的动作。球是当前真实 Memory ID 的空间表示，不能另生成一条虚构记录。

| 时间 / 阶段 | 身体与情绪 | 球、眼神与相机 | 事件与审核点 |
| --- | --- | --- | --- |
| 0–0.35 s · 发现 | E01 → E02，眼神先停在实际结果球 | 目标有可追踪的世界位置；镜头给球和脸同时留白 | 只有检索得到有效 ID 才进入 `attention`；无结果不演「找到」 |
| 0.35–0.9 s · 准备 | 头微侧倾，胸廓轻朝目标，E02 → E03；左肩放松 | 视线落点由球心提供，头转动滞后 | 可见思考停顿，时长有限，不用额外长台词 |
| 0.9–1.75 s · 伸手 | 上臂前送、肘展开，掌心逐步朝上；手指从放松到承接形 | 球仍在原位，手臂不能提前硬吸附到球 | `summoning`；到达 authored `palm_ready`，实际掌心稳定后才开始球移动 |
| 1.75–3.1 s · 球靠近 | 手掌维持稳定；眼睛连续跟球，头少量跟随；E03 柔化 | 球沿无穿身的三维弧线到手前，速度先起再缓；镜头不要追球猛摇 | 动画时长是参考，实际到达由距离/速度判定；路径与真实掌心锚点相关 |
| 约 3.1–3.45 s · 缓冲承接 | 球临近时 E05 短暂轻惊喜，腕/肘略下沉后稳定，指尖轻围合 | 球悬于掌心上方，不嵌入掌心；高光不遮脸 | `orb_arrived` + 掌心在允许区域，播放 `summon_catch`；不能只到时间就进入 presenting |
| 3.45–4.65 s · 展示 | 手掌缓慢向用户打开，胸转回；E06，视线先看球再邀请用户 | 球持续跟随手锚点，不丢失原 Memory ID；保持眼睛和球分离的构图 | `presenting`；阅读入口绑定同一真实记录，现有详情能力不改 |
| 4.65 s–关闭 · 停留 | 轻呼吸，持球臂小幅自然支撑；不连续反复招手 | 球稳定悬浮，阅读时不强迫相机移动；视线不持续来回扫 | hold 不重复播放 catch；用户可随时阅读/关闭/取消 |
| 关闭后 0–1.6 s · 释放 | 掌心轻转放开，视线送球返回，手回落，E06 → E01 | 球回到该 ID 的布局位置；若记录已删则淡出临时球表现 | 恢复仅改变展示位置，不写入 Memory 内容或持久坐标；随后 `idle` |

### 掌心、眼神与真实空间约束

- 提案球半径约 5.5 cm；按新模型标定的 palm socket 法线偏移「球半径 + 1–2 cm」形成悬浮接触，球心不与手骨原点重合。世界锚点须由最终骨骼矩阵计算，不能直接沿用样本 `palmOffset`。
- 捕捉目标使用带速度连续性的路径。远处跟随可更新终点，最后约 0.3 s 稳定预测终点并通过 catch 小范围 IK 校正；不可每帧重新起算整个弧线造成永不到达或抖动。
- 掌心超出肩臂自然可达区时，调整演员转向/构图或拒绝当前姿态，不能拉伸手臂。球路线避免头、胸、袖和前臂；简单碰撞不足时重新设计轨迹，不用光效遮住穿模。
- 手势标记与实际到达条件分开；先完成伸手，球再来；接近时保留眼神连续；真正到掌心后才展示。程序不能用一条总时间轴替代所有交互事件。
- 与记忆情绪无关的「找到、好奇、承接成功」可用预设表情；不读取正文推断情绪，也不把私人记录交给外部模型或画师。拍样片使用隔离的明确标注测试记录。

## 动画衔接、失效与减少动态效果

默认 cross-fade 约 0.2–0.45 s，按动作接触点微调；接地足和托球手在过渡中保持约束，不因线性权重混合漂移。身体、脸、眼、手分别声明轨道控制者。到达被取消、目标删除、模型载入失败、后台恢复均有回落路径，不能留下无尽 hold。

减少动态效果不意味着绕过真实事件：改为简短 attention → 静态手势 → 到达姿态，镜头采用现有短转场，球用短距离或淡入式位置变化；只有位置实际就绪才展示。暂停重复重心、长摆动和强烈耳动。不强迫长时间等待完整表演才能看记忆。

## 动画师交付与视觉验收

每段交付四张到八张关键帧绘图及带时间码预演，标注 gaze、接地脚、重心、手掌朝向、球路线、镜头和事件点。精修后交付 DCC 源文件、VRMA/必要的额外骨轨道、接续姿态表、事件标记表及至少 1080p/30 fps 的无剪辑录像。预演/最终版本分别标识。

验收影片需包含：

1. A 连续 60 s、正面与侧面；检查重复感、脚滑、呼吸、表情与发裙衰减。
2. B 左/右/背后目标各一遍，长短旅行各一遍，飞行中取消一遍；镜头实际抵达前没有欢迎。
3. C 远/近/偏侧球体、伸手/飞行/托球阶段取消、目标删除；展示与阅读始终对应同一真实 ID。
4. 中性光与产品深空光各一遍，脸和手近景；慢放检查眼皮、袖腋、肘腕、指节、发肩和裙腿。

这些是**下一阶段待制作、待执行的验收项**。本轮文字分镜不等于动画样片，现有旧样本截图不用于证明本设计的自然度。
