## 核心提案

角色暂以制作编号 `UOM-G01` 管理，不替用户确定最终姓名。延续成年女性设定，约 7.2 头身；银蓝长发、自然狐耳、深靛交领长衣，以偏心星轨扣和前短后长的分层衣摆形成独立轮廓。借鉴参考中的灵动、柔和、狐妖幻想气质，不复制其幼年比例、五官、发饰、服装或标志性配色。

性格通过节奏呈现：她会先观察、再行动；找到目标时有一瞬好奇；托住记忆时收敛为温柔、专注。不会替用户判断一段真实记忆应该令人快乐或悲伤。

动作以人工制作的动画片段为主体，目标追踪、掌心对齐和头发衣物物理做补充。完成概念图与表演样片审核后，才进入正式模型接入。

## 当前可实现程度

- **已有技术基础：** VRM1 加载、VRMA 导入、真实骨骼与视线、事件状态机、相机到达回报、真实记忆球到掌心、取消与只读边界。
- **可制作但尚未完成：** 原创脸型/狐耳/服装模型、六表情、精修身体与手指动画、贴合新角色的物理与材质。
- **需要新的集成验证：** 分层动画的写入权、额外狐耳骨轨道、脚步接地、动态目标重定向、正式旅行中的角色空间。不能承诺仅换一个 VRM 文件就会自然表演。

## 建议审核顺序

1. 依据已选方向 A 先制作原创人物效果图，取得用户明确确认；再以同一外观基准绘制三视图与六表情。效果图未确认不正式建模，结构图仍需一致性审核。
2. 用一致的原画制作中性光照转台、表情与权重测试。
3. 先做三段动画的粗分镜/预演，再做完整动作；粗预演明确标识，不作为最终角色效果。
4. 在 `/guide-lab` 用最终候选模型逐段录制、检查事件与真实记忆球，再决定是否进入正式页面。
