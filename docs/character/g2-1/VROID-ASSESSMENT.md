## 唯一外观依据

只使用 [完整效果图](../g1-5/source/approved-beauty.png) 与 [三视图 v1](../g1-5/source/turnaround-v1.png)。本轮重新核验两图 SHA-256，与 [baseline.json](../g1-5/baseline.json) 一致；现成 [参考核对页](../g1-5/review.html) 包含脸部裁切和比例对齐。它是参考资料，不是新模型预览。

制作者应对照以下可见特征，不使用旧文字设定中的固定头身数替代原图：

- 脸：柔和收窄的下颌、小而不尖硬的下巴、轻微面颊体积；避免球形人偶头。正面审轮廓，侧面审额头—鼻—唇—下巴曲线，45° 审眼窝与面颊。
- 眼：蓝紫虹膜，细致上眼线和睫毛、柔和下眼睑，眼角形状与眼距要共同匹配；瞳孔、高光和虹膜层次需定制贴图，不能只把默认眼睛染蓝。
- 发：银白/淡紫蓝发根、渐变蓝色长发；非均匀分缝刘海、贴脸侧发、后脑支撑发量和松散长发分组。通过大小疏密变化、弧线与收尖体现层次，拒绝等宽等距硬长条。不得把效果图直接投影当完整发型。
- 耳：保留当前狐耳轮廓及头顶空间，头发分组避开未来耳根。此阶段只在对照图标注未来耳根位置；不把通用 VRoid 兽耳直接当作已还原，也不急做最终耳毛/物理。
- 身体：保持成年、自然的肩颈和四肢比例，以三视图可见关节点评估；高跟鞋、透视、裙摆和发量会影响视觉身高，不能直接用整幅图像高度算裸身体比例。用简单不透明基础服装验形。

两图并非严格一致的正交蓝图；有冲突时先保留并标注，不拉伸图片凑一致。脸部气质以效果图重点审查，结构以三视图辅助，无法判定的位置留给用户视觉确认。

## 最少人工制作流程与停止点

1. **准备编辑器（人工一次）**：从官网安装；若官网浏览器也不可达，使用 pixiv 官方 Steam 发行页。安装与条款由使用者正常操作，不需要改系统执行策略。记录版本，启动一个临时项目确认视口和保存可用。官方预设只用于启动和技术检查，不交付为人物成品。
2. **脸部第一关（必须人工美术编辑）**：新建独立项目，调整脸轮廓/眼距/眼睑/鼻唇/肩颈，绘制眼睛、眼线和必要皮肤细节；先用少量发型轮廓留出脸部。保存 `silver-spirit-face-v001.vroid`，提交中性表情的正面、45°、侧面真实视口截图或渲染。任一角度仍明显是通用脸，则停止扩展服装和全身细节。
3. **头发与基础比例第二关（必须人工美术编辑）**：脸部得到认可后再做分组长发、刘海/侧发、银蓝渐变与自然身形。保存 `silver-spirit-head-body-v001.vroid`，交付头部三角度和全身正面比例预览。耳/尾/礼服仅预留连接区域，本轮不制作复杂饰品或动画。
4. **取景、对照、交付（可自动辅助）**：取得真实导出模型后，用现有 Blender 环境检查导入与材质，建立统一中性光照、固定镜头，输出 PNG 和原画并排对照；保留原始渲染不修脸、不重绘、不用生成式图片替代模型。当前尚无新源工程，故未执行此步。
5. **超出 VRoid 的明确出口**：若鼻唇/侧脸或眼睑造型被滑块上限限制，由熟悉日系动漫拓扑的 Blender 制作者从新的 VRoid 底模精修，另存 `.blend` 并管理 UV/法线。若连 VRoid 底模都限制目标脸型，则委托专用动漫头部拓扑制作；不回到旧程序化草稿，也不靠反复换通用样本试错。

不承诺“自动一键原画转 3D”或未经实际工作的工时。学习 VRoid 能降低操作门槛，不能省略美术判断；用户追求的高还原度更适合有动漫脸部与手绘发型经验的制作者。
