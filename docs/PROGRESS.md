## 主要手动验收路径

### 桌面 / 存储

1. 固定 `http://127.0.0.1:3000` 打开首页；看见五颗明确标为示例、未自动命名的星球，控制台无渲染错误。
2. 拖动旋转、滚轮缩放、双指操作；点选星球资料变化；双击/「靠近」平滑飞行；「返回全景」恢复全景。
3. 创建空名称草稿，确认保留 `null`；创建自命名星球，设置日期/星系/纹理/颜色/环；保存出现在不同坐标，刷新资料仍在。
4. 设定结束早于开始，保存应报错且表单仍保留；勾选持续后结束清空。
5. 点击进入，观察靠近与淡入；URL 是该星球 ID。新增两条不同日期文字，编辑、切换排序、刷新、取消删除与确认删除均正常。
6. 返回宇宙，镜头位置恢复。搜索名称和介绍，筛选跨年份阶段，清除筛选，验证无结果提示。
7. 切换渲染质量、启用系统减少动态效果；核查主场景与预览均停止自转。
8. 导出 JSON，与记录数/日期/正文核对。双标签页编辑，确认状态同步；模拟 stale revision 时拒绝覆盖。
9. 在独立测试浏览器配置中模拟损坏数据/存储配额；确认不重置档案，错误可理解、原文可导出。

### 手机 / 可访问性

1. 390×844 与 360×740 视口，不横向溢出；列表横向滚动，选中后列表收起、信息卡可见。
2. 全部表单字段、日期、类型与颜色可操作；dialog 可滚动、底部保存可达，键盘不遮挡永久阻塞。
3. 仅键盘完成列表选择、编辑、直接进入档案、关闭 dialog；焦点返回触发控件。
4. 在无 WebGL 环境中仍通过列表与直接链接进入档案，不依赖飞行完成回调。
5. 在至少一台实际手机验证触控、帧率与发热；自动模式目前只是启发式，不能以模拟器代替真实性能测试。
